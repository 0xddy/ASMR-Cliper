# ASMR-Cliper 0.6.3

Windows 10/11 x64 本地 ASMR 自动剪辑工具。支持音频和视频，识别并删除说话片段，保留所选 ASMR 声音。分析与模型推理均在本机完成，媒体文件不会上传。

## 使用

完整集成包的构建与下载方式见 [win64-nv 打包说明](docs/BUILD_WIN64_NV.md)。解压后运行 `ASMR-Cliper\asmrcliper.exe`。

1. 打开「运行环境」检查组件；如有缺失，点击「补齐环境」。模型和下载代理可在界面设置。
2. 在「剪辑任务」选择音频或视频、输出目录、输出类型和模式，默认使用 V3。
3. 在「偏好设置 → 保留声音」选择想留下的声音，然后开始剪辑。
4. 完成后在「处理记录」播放结果、查看复核记录或打开结果目录。

语音识别支持 Whisper large-v3、Whisper Turbo 和 Qwen3-ASR；识别与成片复核模型可分别选择。环境就绪后，正常剪辑无需联网。

## 三种模式

| 模式 | 适用取向 |
|---|---|
| V2 严格 | 扩大说话附近的删除范围，优先保留连续长段 |
| V3 宽松 | 尽量保留能自然衔接的完整 ASMR 动作 |
| V4 提取 | 仅提取有 ASMR 声音证据的片段，必须通过成片复核 |

完整规则见 [模式说明](docs/模式提示词.md)。提示词文件用于说明规则，修改文字不会自动改变引擎行为。

## 输出

支持「跟随输入」「仅音频」「视频（原编码）」。成片复制原始编码包，不重新压缩；视频切点受关键帧限制，可能额外删去边缘片段。

每次任务创建独立结果目录，保存成片、剪辑时间对照、复核记录和校验报告。自动识别可能误删或漏删，建议复听成片，尤其是标为「待复听」的位置。

## 从源码构建

安装 Visual Studio 2022 C++ 桌面开发工具、Windows SDK 和 CMake 3.24+，然后运行：

```powershell
.\scripts\build.ps1
```

程序生成在 `bin\asmrcliper.exe`。源码不包含 Python 运行环境、模型或 FFmpeg，可通过程序内的「运行环境」安装，详见 [环境管理说明](docs/ENVIRONMENT.md)。
