# ASMR-Cliper 0.6.7

Windows 10/11 x64 本地 ASMR 自动剪辑工具。支持音频和视频，识别并删除说话片段，保留所选 ASMR 声音。分析与模型推理均在本机完成，媒体文件不会上传。

## 使用

完整集成包的构建与下载方式见 [win64-nv 打包说明](docs/BUILD_WIN64_NV.md)。解压后运行 `ASMR-Cliper\asmrcliper.exe`。

1. 打开「运行环境」检查组件；如有缺失，点击「补齐环境」。模型和下载代理可在界面设置。
2. 在「剪辑任务」选择音频或视频、输出目录、输出类型和模式，默认使用 V3。
3. 在「偏好设置 → 保留声音」选择想留下的声音，然后开始剪辑。
4. 完成后在「处理记录」播放结果、查看复核记录或打开结果目录。

语言设为「自动识别」时，识别后会暂停并弹窗确认；可以改选语言后继续当前任务。手动指定语言则直接处理。

任务底部显示阶段、复核轮次、音频块及窗口进度。复核显示的是**本轮进度**，通过即结束，不一定跑满最大轮数。耗时从启动任务开始计算，包含等待语言确认的时间，完成或取消后停止；完成记录中也会保存耗时。

语音识别支持 Whisper large-v3、Whisper Turbo 和 Qwen3-ASR；识别与成片复核模型可分别选择。环境就绪后，正常剪辑无需联网。

## 三种模式

| 模式 | 适用取向 |
|---|---|
| V2 严格 | 扩大说话附近的删除范围，优先保留连续长段 |
| V3 宽松 | 尽量保留能自然衔接的完整 ASMR 动作 |
| V4 提取 | 仅提取有 ASMR 声音证据的片段，必须进行成片复核 |

完整规则见 [模式说明](docs/模式提示词.md)。提示词文件用于说明规则，修改文字不会自动改变引擎行为。

## 输出

支持「跟随输入」「仅音频」「视频（画面原编码）」。默认复制原始编码包，不重新压缩；开启可选的接缝淡化后音轨重新编码。视频始终复制原编码，切点受关键帧限制，可能额外删去边缘片段。

每次任务创建独立结果目录，保存成片、剪辑时间对照、复核记录和校验报告。自动识别可能误删或漏删，建议复听成片，尤其是标为「待复听」的位置。

V2 / V3 / V4 在复核轮数用尽后仍有疑似话语时，都会保存成片并记录为「已完成，待复听」。在处理记录中选择结果，点击「待复听位置」可直接查看成片时间及识别文字；结果目录同时保存 `人声复核.csv`。模型执行或导出校验错误仍会停止任务。

## 最长空窗期

「偏好设置 → 剪辑参数 → 最长空窗期（秒）」默认 **1.5 秒**，支持 0.3–10 秒，V2 / V3 / V4 共用。按成片连续静音计算，包括两个片段拼接后叠加的停顿；超过上限时剪去静音中间部分。旧版的 7 秒检测阈值不再沿用。静音由各声道电平及峰值共同判断，短暂停顿和有细微峰值的声音不会因静音规则被一并压缩。

规划为音频包边界和可选淡化预留时间；淡化时长也会随空窗上限自动收紧。视频按完整关键帧片段进一步调整，可能额外删去边缘画面。导出后实测连续低电平空窗，报告记录 `pause_check`；如编码边界或声音判定导致仍有超限，具体位置保存在 `空窗检查.csv`，日志明确提示。

## 可选接缝淡化

在「偏好设置 → 音频过渡」开启「接缝淡出 / 淡入」。默认关闭；每侧默认 0.3 秒，可设为 0.05–2 秒，实际时长同时受最长空窗期约束。开启后在每个接缝前淡出、接缝后淡入，减轻音量突然升降的听感；短片段自动缩短，保留中间至少一半不淡化。适用于 V2 / V3 / V4，不重叠片段，淡化滤镜本身不改变成片时长或音画同步，也不做全片响度归一化。

音频滤镜需要重新编码音轨。编码类型、采样率和声道保持一致，有损编码的目标码率沿用源音轨，实际平均码率会变化；视频画面仍原包复制。没有接缝时跳过淡化和重编码。不支持的源音频编码会明确报错，可关闭开关继续原包输出。

语音复核检查淡化后的实际音轨，节目单也读取最终成片。处理记录标明淡化时长，结果目录保存 `接缝淡化.csv`，记录接缝位置、实际淡入淡出长度及两侧 RMS 音量差，方便对比开关效果。

## 成片节目单

剪辑完成后，读取**实际成片的音轨**，由本地 CLAP 声音语义模型识别项目，按播放顺序生成带时间的节目单。支持口腔音、刷麦、摩擦、道具敲击、心跳等；连续同类项目合并，相似或证据不足的声音标为「混合 ASMR」或「待确认」，并标注重叠的待复听位置。

在「处理记录 → 查看节目单」阅读或复制，结果目录同时保存 `节目单.txt`、`节目单.csv`、`节目单.json`。旧成片可从「生成节目单」补生成。自动生成默认开启，可在「偏好设置 → 成片节目单」关闭。

节目单只描述成片，不参与剪辑、调整顺序或修改媒体文件。项目切换时间约为 5 秒精度，音色相似的舔耳与湿润口腔音采用合并名称，不保证识别出具体道具或动作意图。需要运行环境中的 CLAP 和独立音频模型依赖；缺少模型或取消生成时，已完成的成片仍保留。

## 从源码构建

安装 Visual Studio 2022 C++ 桌面开发工具、Windows SDK 和 CMake 3.24+，然后运行：

```powershell
.\scripts\build.ps1
```

程序生成在 `bin\asmrcliper.exe`。源码不包含 Python 运行环境、模型或 FFmpeg，可通过程序内的「运行环境」安装，详见 [环境管理说明](docs/ENVIRONMENT.md)。
