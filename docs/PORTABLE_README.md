# ASMR-Cliper · win64-nv

完整解压后，双击本目录的 **asmrcliper.exe**。请放在可写目录中；输出、设置与工作缓存保存在软件目录下。保留整个目录结构，可以整体移动到其他路径。

已集成两套 Python、NVIDIA 推理依赖、FFmpeg 和全部可选模型，不需要另外安装 Python 或 CUDA Toolkit。NVIDIA GPU 加速需要电脑已安装兼容的显卡驱动；默认自动选择设备。

1. 在「剪辑任务」选择音频或视频、输出目录、模式和输出类型，开始剪辑。
2. 在「运行环境 → 模型选择」选择 Whisper large-v3、Qwen3-ASR-1.7B 或 Whisper Turbo，设置成片复核模型。
3. V2 删除范围较大；V3 尽量寻找自然过渡；V4 仅提取有 ASMR 证据的部分。说话始终排除。
4. 「偏好设置」可调整剪辑参数、要保留的声音和下载代理。集成包默认直连，首次启动只检测环境。

音频和视频输出复制源编码包。视频切点受关键帧限制，可能额外删去边缘片段。模型识别和成片复核不能保证完全没有漏删，成片可在「处理记录」复听。

模型与依赖清单、构建来源及验证结果见 `build-info.json`；第三方说明见 `THIRD_PARTY_RUNTIME.md`。详细模式说明见 `docs/模式提示词.md`。
