# 模式提示词

可选接缝淡化：以下原包复制要求是默认关闭淡化时的行为。若用户开启音频过渡，则在实际接缝前淡出、后淡入，每侧默认 0.3 秒，短片段或空窗上限较小时自动缩短；仅音轨重新编码，保持编码类型、采样率、声道和源目标码率，视频画面仍原包复制。片段不重叠，时长和顺序不变；先淡化后语音复核，再分析最终成片节目单。此显式开关优先于下文默认不添加淡化的要求。

三种模式共用的音色中断检查：声音相对前一动作突然变闷或高频细节明显减少，持续几秒后又开始新的 ASMR 时，先把中间阶段列为候选，单独检查其内部，不能让后面的 ASMR 掩盖它。确认仍有低频口腔音、摩擦、心跳、敲击等有效动作时保留；只有前后 ASMR 与内部非 ASMR 背景残留的证据共同成立，才删除中断阶段并寻找自然切点，不设固定外扩秒数。纯音量变化、频率低或未检出说话都不是删除理由；证据不足不据此自动删除，V4 仍需满足其正向提取规则。原编码、采样率和播放速度不变。

严格模式（V2）

请把这段 ASMR 直播录音剪辑为以连续非语言 ASMR 为主的音频，保留舔耳、口腔音、摩擦音等有效声音动作，删除说话、聊天、背景音乐和长时间静音。以减少突兀感、减少零碎跳切为优先，可以多舍弃一些内容。

与 V3 共用的声音选择：说话声始终删除，包括带情绪、拖长、惊讶、喊叫或轻声的话语，不能因为转写不完整或混有口腔音就放行。其他类别遵循用户“保留声音”的选择，勾选表示保留；默认保留轻笑、心跳和 ASMR 道具敲击，删除大笑、呼气/烟雾、喝水休息、物品掉落 / 突兀撞击。用户的当前选择优先于这些默认值。取消勾选心跳或 ASMR 道具敲击时，排除检出的对应动作；有规律的道具敲击与掉落、孤立撞击分开判断。轻笑不应仅因模型同时标为一般人声而被删除；与实际话语重叠或无法自然衔接的部分仍按上下文舍弃。

对于未勾选的中断声音：大笑按完整笑场处理，包含相连的吸气、拖尾与停顿；喝水按直播中场休息处理，结合拿杯、饮用及前后停顿；呼气/烟雾按检测到的持续气流和吸入、吐气等完整动作处理，不将声音分类当成设备身份识别。向外寻找自然边界，恢复稳定 ASMR 时停止。物品掉落或突兀撞击需结合音色、突变和上下文，不能只按音量删除。检查每个候选片段内部，不能只检查两端；普通短呼吸、水声、敲击、口腔音或噼啪声不能单独作为整段删除依据。

1. 以完整说话段落确定删除范围，不只精准挖掉字词。默认在说话前额外删除约 5 秒，结束后额外删除约 7 秒，再向外寻找较安静的声音边界，避开准备发声的吸气、话语拖尾和未完成的动作。
2. 密集聊天区域按较大的连续段落处理，允许把夹在话语之间的短暂 ASMR 一并删除；相邻删除区间较近时合并，默认合并间隔为 20 秒。
3. 优先保留较长、连续且内容明确的 ASMR。默认要求连续片段达到约 40 秒；静音缩短只压缩已批准场景内的停顿，不因缩短而再次丢弃同一场景中的短段声音。
4. 最长空窗期默认 1.5 秒，可在剪辑参数中设置。结合各声道电平与峰值识别静音，剪去过长停顿的中间部分；按最终播放顺序累计两侧余量，避免跨片段拼接后超限，同时为音频包和可选淡化预留时间。
5. 这些数值是严格模式的默认参数，可以根据录音修改。交付时说明实际参数、保留时长和剪辑段数，并提供原片与成片的时间对照。

音质要求：只做剪辑，原编码音频包直接复制，不重新编码，不调整音量，不降噪，不添加淡入淡出或交叉淡化。编码类型、采样率和声道保持一致。VBR 的显示平均码率可能随所保留的内容变化，不能把平均码率变化误认为重编码。

复核要求：检查剩余说话、首尾和接缝；校验保留压缩帧与原文件一致，并检查完整解码。对自动分析仍无法确定的接缝给出复听位置，不声称绝对无缝。

成片模型复核：默认启用所选本地完整语音模型（Whisper large-v3 或 Qwen3-ASR） 检查实际候选成片的完整时间轴。发现疑似话语时映射回原录音、重选自然切点并再次复核，默认最多 3 轮；仍有疑似话语时保存成片并明确标为“待复听”，附成片疑似位置；不能显示为复核通过。若用户明确关闭此项，报告必须标明未复核。

宽松模式（V3）

请把这段 ASMR 直播录音剪辑为以非语言 ASMR 为主的音频，保留舔耳、口腔音、摩擦音等完整声音动作，删除说话、聊天、背景音乐和长时间静音。优先保证听感自然，同时尽量保留能自然衔接的有效内容。

与 V2 共用的声音选择：说话声始终删除，包括带情绪、拖长、惊讶、喊叫或轻声的话语，不能因为转写不完整或混有口腔音就放行。其他类别遵循用户“保留声音”的选择，勾选表示保留；默认保留轻笑、心跳和 ASMR 道具敲击，删除大笑、呼气/烟雾、喝水休息、物品掉落 / 突兀撞击。用户的当前选择优先于这些默认值。取消勾选心跳或 ASMR 道具敲击时，排除检出的对应动作；有规律的道具敲击与掉落、孤立撞击分开判断。轻笑不应仅因模型同时标为一般人声而被删除；与实际话语重叠或无法自然衔接的部分仍按上下文舍弃。

对于未勾选的中断声音：大笑按完整笑场处理，包含相连的吸气、拖尾与停顿；喝水按直播中场休息处理，结合拿杯、饮用及前后停顿；呼气/烟雾按检测到的持续气流和吸入、吐气等完整动作处理，不将声音分类当成设备身份识别。向外寻找自然边界，恢复稳定 ASMR 时停止。物品掉落或突兀撞击需结合音色、突变和上下文，不能只按音量删除。检查每个候选片段内部，不能只检查两端；普通短呼吸、水声、敲击、口腔音或噼啪声不能单独作为整段删除依据。宽松模式不会降低说话声的排除标准。

1. 不使用“说话前至少 5 秒、结束后至少 7 秒”一类固定外扩规则。逐处根据声音的实际情况确定切点：包括准备说话的吸气、语气变化、动作停顿、听者对即将发声的预期、话语拖尾，以及稳定 ASMR 恢复的位置。
2. 删除范围可以向外扩大，但目的是保住完整的声音动作和自然过渡。较近位置已经可以自然接上时，不必为了达到固定秒数而继续删除；附近接不顺时，继续向外寻找合适切点。
3. 不因“聊天密集”就直接整段删除。先逐一判断话语之间的 ASMR 能否完整收尾并自然衔接；可以则保留。只有继续调整仍无法兼顾过渡、保留后会显得突兀，或只剩不完整的声音碎片时，才扩大到整段舍弃。
4. 在声音动作之间的自然停顿或合适的低能量位置拼接，避免把吸气、舔耳或其他动作截到一半。正常的短停顿保留；连续静音按最长空窗期设置收紧，默认 1.5 秒，跨接缝的余量共同计时。
5. 时长与聊天密度只作参考，不用固定的最短长段要求一刀切地排除所有短 ASMR。能完整、自然保留的短段也可以保留。交付原片与成片的时间对照，并记录切点和舍弃片段的理由。

音质要求：只做剪辑，原编码音频包直接复制，不重新编码，不调整音量，不降噪，不添加淡入淡出或交叉淡化。编码类型、采样率和声道保持一致。VBR 的显示平均码率可能随所保留的内容变化，保留帧不得重新压缩。

复核要求：再次检查轻声说话及其上下文，必要时重新选择声音边界；校验保留压缩帧和完整解码，检查接缝突变。对自动分析仍无法确定的地方给出复听位置，不声称绝对无缝。

成片模型复核：默认启用所选本地完整语音模型（Whisper large-v3 或 Qwen3-ASR） 检查实际候选成片的完整时间轴。发现疑似话语时映射回原录音、重选自然切点并再次复核，默认最多 3 轮；仍有疑似话语时保存成片并明确标为“待复听”，附成片疑似位置；不能显示为复核通过。若用户明确关闭此项，报告必须标明未复核。

提取模式（V4）

仅提取声音证据明确、完整且能自然衔接的 ASMR 动作，如舔耳、口腔音、摩擦、心跳或有规律的道具敲击。未知声音、无法确定用途的声音和单次分类命中不作为提取依据，宁可少留，也不把“没识别出说话”当成“确认是 ASMR”。

1. 从连续的正向声学证据建立候选区间；检查内部与边界，而非先把整段录音视为可保留。
2. 说话声始终删除，包括耳语、短促情绪话语与残留词尾。呼气/烟雾、喝水休息、大笑和突兀撞击不作为提取目标。保留选项仅表示允许保留，不会把非 ASMR 变成正向证据；默认勾选轻笑、心跳和 ASMR 道具敲击；轻笑可随符合条件的 ASMR 上下文保留，心跳与道具敲击需连续正向证据。取消对应勾选后，即使存在 ASMR 证据也排除该类动作。
3. 避开发声准备、相连的吸气、未完成动作和拖尾，向外寻找自然边界；找不到自然衔接点的片段舍弃，不按固定前 5 秒 / 后 7 秒一刀切。
4. 候选成片生成后必须调用本地成片复核模型，覆盖实际成片的完整时间轴与拼接处。检出话语时映射回原录音、重新调整切点并再次生成复核，默认最多 3 轮。达到轮数仍有疑似话语时，保存成片并标记为“已完成，待复听”，把成片疑似位置和识别文字记录到处理记录；不能标记为失败或复核通过。若继续调整将无法保留片段，则保存当前有效候选并标记待复听。
5. 只复制原编码音频包，不转码、不调整音量、不降噪、不添加淡化。校验原始包一致性和完整解码，提供时间对照、正向证据区间及复核结果。

“确认”指达到本地模型与规则设定的证据标准，不等于人工听审或绝对保证。声学分类分数不是 ASMR 的校准概率；保留模糊片段的需求应使用宽松模式。

实现依据：使用 CLAP 比较 ASMR、说话、休息等声音描述，并结合基础声学证据；连续动作内允许证据强弱变化，不因单个通用标签分数降低就反复切碎。未知内容和已排除话语不能借相邻正向片段重新进入成片。分数不等于人工确认。

视频输出：音视频共同剪辑并复制源编码，视频关键帧边界只向允许保留的区间内部调整。成片复核与时间对照使用实际导出时间轴，不将被删除的内容补回来。
